# Security

ooxml-pages renders untrusted files. A document that makes it run script, load something from the network, or use memory or time far out of proportion to its size is a security problem.

Please report such problems privately through [GitHub's private vulnerability reporting](https://github.com/Kai-Jungsthoefel/ooxml-pages/security/advisories/new), not in a public issue. Include the file (or how to build it) and the browser you used.
